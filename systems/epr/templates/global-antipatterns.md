## 범용 안티패턴 (Global Anti-Patterns)

### EP-G0001: 목적 앵커 없이 서브에이전트 위임
<!-- EPR: id=EP-G0001, level=global, severity=critical, created=2026-06-07, trigger_count=0 -->

**증상**: 서브에이전트가 Main의 원래 목적과 무관한 결과를 반환

**근본 원인**: 서브에이전트에게 작업을 위임할 때 전체 맥락(왜 이 작업이 필요한지)을 전달하지 않으면, 서브에이전트는 표면적 요청만 처리한다

**잘못된 접근**: 
```
"ADHD 관련 논문을 5개 찾아줘"
→ 서브에이전트가 키워드 매칭으로 관련성 낮은 논문 반환
```

**올바른 접근**:
```
"우리의 목적은 '청소년 ADHD 증가 원인 규명'이다. 
이 목적에 기여할 수 있는, 2020년 이후 발표된 
역학 연구 또는 메타분석 논문을 5개 찾아줘.
각 논문이 우리 목적에 어떻게 기여하는지 설명하라."
→ ICIP의 목적 앵커를 프롬프트에 포함
```

**탐지 조건**: 
- 트리거 키워드: [서브에이전트, 위임, 병렬, 조사, 찾아줘]
- 관련 시스템: ICIP가 비활성화된 상태에서 서브에이전트 호출

**적용 범위**: 모든 서브에이전트 위임 작업

### EP-G0002: Compaction 없는 장기 대화
<!-- EPR: id=EP-G0002, level=global, severity=high, created=2026-06-07, trigger_count=0 -->

**증상**: 대화가 길어지면서 에이전트가 초반 지시사항을 "잊는" 현상. "아까 말한 것"을 기억 못함

**근본 원인**: LLM의 "lost-in-the-middle" 현상. 컨텍스트 윈도우의 시작과 끝은 잘 인식하지만, 중간 부분의 정보는 주의력이 떨어진다

**잘못된 접근**: 
```
동일 세션에서 30턴 이상 대화하면서 compaction 없이 진행
→ 에이전트가 10번째 턴의 지시사항을 무시
```

**올바른 접근**:
```
TCM 시스템 활성화:
- 15턴 시점에서 프록시 지표 점검
- Soft Compaction으로 이전 대화 요약
- 목적 앵커를 Tier 1에 유지
```

**탐지 조건**: 
- 트리거 키워드: [기억 못하나, 아까 말한, 처음부터 다시, 방금 설명한]
- 관련 시스템: TCM 비활성화 상태에서 장기 대화

**적용 범위**: 15턴 이상의 모든 대화

### EP-G0003: 체크포인트 없는 복잡 작업
<!-- EPR: id=EP-G0003, level=global, severity=high, created=2026-06-07, trigger_count=0 -->

**증상**: 작업 중단 후 재개 시 "처음부터 다시 해야 하는" 상황

**근본 원인**: 중간 진행 상태를 파일로 기록하지 않아 세션 종료 시 모든 맥락 손실

**잘못된 접근**: 
```
3-Phase 작업을 Phase 2까지 완료했으나 checkpoint 없이 세션 종료
→ 새 세션에서 Phase 1부터 재시작 필요
```

**올바른 접근**:
```
CRP 시스템 활성화:
- 각 Phase 완료 시 checkpoint.json 자동 갱신
- 새 세션 시작 시 checkpoint.json 확인 → Phase 3부터 재개
```

**탐지 조건**: 
- 트리거 키워드: [여러 단계, multi-phase, 복잡한 작업, 오래 걸리는]
- 조건: 예상 작업 시간 > 30분 또는 Phase > 2개

**적용 범위**: 2개 이상의 Phase로 구성된 모든 작업
