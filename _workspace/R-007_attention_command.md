### R-007: Attention Command Workflow
<!-- RULE: id=R-007, priority=MUST, scope=project -->
<!-- RULE: category=workflow, enforceable=true, auto_check=true -->

**규칙**: 사용자가 `/attention` 이라는 명령어(또는 키워드)를 입력하면, 에이전트는 즉시 임의의 수정을 멈추고 현재 코드베이스의 상태 파악(최근 작업 내역, `00_purpose_anchor.md`, `checkpoint.json` 등)을 수행한 뒤, 파악된 컨텍스트를 요약 보고하고 사용자의 다음 구체적인 의도(Intent)를 수용할 준비가 되었음을 명시적으로 알린다.

**이유**: 코드베이스를 장기적으로 발전시키기 위해, 에이전트가 기존 맥락을 잊지 않고 사용자의 새로운 지시에 온전히 집중(Attention)할 수 있도록 강제하는 명확한 컨텍스트 동기화 진입점(Entry Point)이 필요하기 때문이다.

**검증 방법**:
- [ ] `/attention` 입력 시 에이전트가 즉각적인 코드 수정을 시도하지 않았는가
- [ ] 프로젝트의 현재 상태와 앵커 목표를 요약하여 브리핑하였는가
- [ ] 다음 명령을 기다린다는 준비 상태를 명확히 응답하였는가

**위반 시 조치**: 작업을 중단하고 코드베이스 컨텍스트 동기화 및 브리핑부터 다시 수행할 것을 지시

**예외**: 사용자가 `/attention` 명령어 없이 곧바로 구체적인 수정 작업을 지시한 경우 (이때는 일반 워크플로우를 따른다)

**예시**:
- ✅ `User: /attention` -> `Agent: (코드베이스 및 최근 체크포인트 리뷰 진행) 현재 코드베이스 상태 파악을 완료했습니다. 다음 지시를 내려주세요.`
- ❌ `User: /attention` -> `Agent: (상태 리뷰 없이 곧바로 특정 파일 수정 시도)`
